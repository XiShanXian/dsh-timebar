# 时间条配置（2026-09-30 更新：峰谷细则 v2026-09-19）

## 形态

- **类型**：24 小时 DeepSeek 百万 TOKEN 价格条（应用顶部固定横条，shell.overlay 浮层）
- **粗细**：2px
- **右端**：顶满（right: 0）
- **指针**：当前时间竖线 + 左侧直角矩形时间标签（HH:MM:SS，24 小时制，每秒更新）
- **配色**：指针与时间标签随当前时段变色
  - 空闲时段（低谷价）→ 绿色 `--dsw-alias-state-success-primary`
  - 高峰时段 → 琥珀色 `--dsw-alias-state-warn-primary`
  - 未知年份（无节假日数据）→ 中性色 `--dsw-alias-state-idle-primary` + 整条斜纹

## 峰谷规则（v2026-09-19，与官方口径一致）

判定基准：**北京时间**；官方按请求「完成」时刻计价，本时间条按「当前时刻」显示。

| 类别 | 时段 | 颜色 |
|---|---|---|
| 高峰时段 | 周一至周五（**不含法定节假日**）09:00–12:00、14:00–18:00 | 琥珀 |
| 空闲时段 | 每日 00:00–09:00、12:00–14:00、18:00–24:00 | 绿 |
| 周末 | 周六、周日**全天** | 绿 |
| 法定节假日 | **全天**（含落在工作日的） | 绿 |
| 调休上班的周末 | **全天仍按空闲价**（官方明确） | 绿 |
| 未知年份 | 全天空闲价 + 灰色斜纹提示 | 灰斜纹 |

> 空闲价 = 高峰价的 **50%**。价目与规则来源：
> [DeepSeek API 文档 · 模型 & 价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)（脚注 2）。

### 节假日数据来源与年度维护

数据表编码在 `lib\client.js` 的 `HOLIDAYS_2026`（节假日）与 `MAKEUP_WORKDAYS`（调休上班日），
来源为**国务院办公厅《关于2026年部分节假日安排的通知》（国办发明电〔2025〕7号，2025-11-04）**：

| 假期 | 放假区间 | 天数 | 调休上班日 |
|---|---|---|---|
| 元旦 | 01-01 ~ 01-03 | 3 | 01-04（周日） |
| 春节 | 02-15 ~ 02-23 | 9 | 02-14（周六）、02-28（周六） |
| 清明 | 04-04 ~ 04-06 | 3 | — |
| 劳动节 | 05-01 ~ 05-05 | 5 | 05-09（周六） |
| 端午 | 06-19 ~ 06-21 | 3 | — |
| 中秋 | 09-25 ~ 09-27 | 3 | — |
| 国庆 | 10-01 ~ 10-07 | 7 | 09-20（周日）、10-10（周六） |

**次年更新步骤**：国务院通知发布后，在 `HOLIDAYS_2026` 旁新增 `HOLIDAYS_2027`，
并入 `HOLIDAYS` 集合，同时把年份加进 `KNOWN_YEARS`，并补充 `MAKEUP_WORKDAYS`。
未加入 `KNOWN_YEARS` 的年份会显示灰色斜纹（宁可漏报高峰，也不误报高价）。
改完跑一遍验证脚本（见下）再重启 DSH。

## 验证

规则逻辑集中在 `lib\client.js` 的 `// @rules-begin` ~ `// @rules-end` 标记块内（纯函数、无 React 依赖）。
验证脚本会**直接抽取该标记块**在 vm 中执行并与断言比对（测的是实际发货代码）：

```
node <会话隔离目录>\verify-timebar-rules.cjs
```

覆盖：窗口边界（08:59/09:00/11:59/12:00/13:59/14:00/17:59/18:00）、
7 个假期、6 个调休日、春节 9 天边界（02-22/02-23/02-24）、
未知年份回退、**2026 全年 365 天 × 3 个时刻逐日交叉核对**（以国务院通知手写区间表为独立期望值）。

另有一个 token 校验脚本（防止臆造主题变量导致渲染透明）：

```
node scripts/check-theme-tokens.cjs lib/client.js
```

### 调试开关（web 端）

`?tbdate=YYYY-MM-DD[THH:MM]` 可用指定时刻渲染时间条，便于核对任意日期配色：

| 地址参数 | 期望表现 |
|---|---|
| `?tbdate=2026-10-02T10:00` | 国庆期间周五上午 → **整条绿色、无琥珀段**（本次修复点） |
| `?tbdate=2026-10-08T10:00` | 假期后首个工作日高峰 → 出现琥珀段、指针与标签转琥珀 |
| `?tbdate=2027-01-04T10:00` | 未知年份 → 中性色斜纹 |

> **桌面端注意**：桌面客户端没有地址栏，无法直接加 URL 参数，该开关对桌面端不实用。
> 桌面端要核对规则，请改系统时钟后**重启 DSH**（时间条读本地时间），核对完务必改回。

## 实现

- 插件：`dsh-diy-timebar`（本仓库）
- 组合行：profile 的 `cordis.patch.yml` 里 `- insert: - id: timebar`
- `<DSH profile>/node_modules/dsh-diy-timebar` 为 junction → 指向本仓库，**随 DSH 启动自动挂载**
- 侧边栏状态感知：占用 `sidebar.footer.action` 空 cell 读取 `wide` 状态，X 自动切换
- 浮层：`shell.overlay`（pointer-events: none，不挡操作）
- 计时：`timer` 服务 interval 1s
- **生效方式**：改 `lib\client.js` 后**必须重启 DSH**（dsh-client-modules 按内容 hash 下发，
  不随 HMR 热替换）
